1. MIT CSINÁL A PROGRAM
--------------------------------------------------------------------------------
Konzolos kvízjáték, amely a népszerű televíziós vetélkedőt modellezi.
- 12 egyre nehezebb kérdésen kell végigmennie a játékosnak.
- 3 játékmód: feleletválasztós, sorrendezős, vegyes.
- Pénzlétra biztos szintekkel (5. és 10. kérdés): ha a játékos hibázik,
  a legutóbbi biztos szint nyereményét viszi haza.
- Segítségek: 50:50 (két rossz válasz eltűnik), közönségszavazás
  (szimulált tipp), kiszállás (aktuális nyereménnyel távozik).
- A kérdéseket CSV fájlokból tölti be, az eredményeket dicsőséglistán
  tárolja (szintén CSV).


2. BEMENETEK
--------------------------------------------------------------------------------
kerdesek.csv – feleletválasztós kérdések
    Nehézség;Kérdés;A;B;C;D;Válasz;Kategória
    Fejlécsoros, ';' elválasztó, 7 pontosvessző soronként.

sorkerdesek.csv – sorrendezős kérdések
    Kérdés;A;B;C;D;Válasz;Kategória
    Fejlécsoros, ';' elválasztó, 6 pontosvessző soronként.

dicsoseglista.csv – dicsőséglista
    Név;Nyeremény;Dátum (ÉÉÉÉ/HH/NN)
    Automatikusan létrejön, hozzáfűzéssel (append) ír.


3. HIBAKEZELÉS
--------------------------------------------------------------------------------
- Fájl megnyitási hiba → hibaüzenet, kilépés.
- Hibás CSV-sor (rossz pontosvessző-szám) → sor kihagyása.
- Üres fájl / hiányzó fejléc → hibaüzenet, kilépés.
- Szintenként túl sok kérdés → felesleges sorok kihagyása.
- Érvénytelen nehézségi szint → sor kihagyása.
- Üres név → alapértelmezett "Jatekos" behelyettesítése.
- ';' karakter a névben → szóközre cserélés (CSV-védelem).
- Érvénytelen válasz → újra bekérés, amíg helyes formátumú.
- 50:50-vel kizárt válasz választása → figyelmeztetés, újra bekérés.


4. A PROGRAM FELÉPÍTÉSE
--------------------------------------------------------------------------------
A program az alábbi fő modulokból áll:

Kérdés-kezelés
  Kétféle kérdéstípust kezel: feleletválasztós (nehézségi szinttel)
  és sorrendezős. Mindkettő ugyanazt az alapműveletet támogatja:
  megjelenítés és válaszellenőrzés.

Játékmenet
  A játékmenet-modul felelős a kérdések szintenként történő
  kiválasztásáért, a segítségek nyilvántartásáért és alkalmazásáért,
  a pénzlétra kezeléséért, valamint a játékos interakciójáért.

Fájlkezelés
  A CSV fájlok beolvasása és a dicsőséglista mentése/betöltése
  elkülönített fájlkezelő modulban történik.

Dicsőséglista
  A játék végén a játékos neve, nyereménye és a dátum rögzítésre
  kerül. A lista bármikor megtekinthető a főmenüből.

Főmenü
  A program induláskor főmenüt jelenít meg: játék indítása,
  dicsőséglista megtekintése, kilépés.


5. FELHASZNÁLT TECHNOLÓGIÁK
--------------------------------------------------------------------------------
- C++ nyelv, objektumorientált tervezéssel.
- STL tárolók és algoritmusok – manuális memóriakezelés helyett
  automatikus élettartam-kezelés (RAII).
- CSV fájlformátum az adatok tárolására.


6. TESZTELÉS
--------------------------------------------------------------------------------
- CSV betöltés tesztek:
    - Üres fájl → 0 kérdés betöltve, nincs crash
    - Hibás sor (kevés/sok pontosvessző) → kihagyva, többi rendben
    - Érvénytelen nehézség (0, 13, -1) → kihagyva
    - Normál fájl → helyes darabszám szintenként

- Játéklogika tesztek:
    - isSafeLevel(4) == true, isSafeLevel(3) == false
    - getSafePrize(3) == 0, getSafePrize(4) == 100000, getSafePrize(9) == 1500000
    - formatPrize(5000000) == "5.000.000"
    - formatPrize(0) == "0"

- Válasz érvényesítés:
    - Feleletválasztós: "A","B","C","D" érvényes, "E","AB","" érvénytelen
    - Sorrendezős: "ABCD" érvényes, "ABC","ABCE","" érvénytelen
    - 50:50 után kizárt válasz → elutasítva

- Dicsőséglista:
    - Üres fájl → fejléc automatikusan létrejön
    - Mentés után visszaolvasás → egyezik
    - Rendezés csökkenő → ellenőrzés

- Segítségek:
    - 50:50: pontosan 2 rossz választ rejt el, helyes marad
    - Közönség: összesen 100%, helyes válasz >= 30%

Tesztelési módszer:
  - Egyszerű assert-ek vagy Google Test / Catch2
  - A logikai függvények (format, safe, check) jól unit-tesztelhetők
  - A fájlkezelést ideiglenes fájlokkal teszteljük
