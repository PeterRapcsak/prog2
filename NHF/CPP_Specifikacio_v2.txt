  2. HOGYAN MŰKÖDIK?
     (A program teljes működésének leírása, elejétől a végéig)
================================================================================

────────────────────────────────────────────────────────────────────────────────
  2.1  Indítás
────────────────────────────────────────────────────────────────────────────────

  A main.cpp-ben mindössze ennyi történik:

    int main() {
        Game game;
        game.loadQuestions("kerdesek.csv", "sorkerdesek.csv");
        game.mainMenu();
        return 0;
    }

  1) Game game;
     → A konstruktor beállítja az alapértékeket (currentLevel = 0,
       gameOver = false, stb.) és meghívja az srand()-ot.

  2) game.loadQuestions(...)
     → A FileManager statikus metódusain keresztül beolvassa a CSV-ket.
     → A feleletválasztós kérdéseket szintenként (1..12) csoportosítja
       a chooseQuestions[0..11] vektorokba.
     → A sorrendezős kérdéseket az orderQuestions vektorba teszi.
     → Beállítja a hasChoose / hasOrder flag-eket.

  3) game.mainMenu()
     → Elindítja a főmenü végtelen ciklust.

  4) Kilépéskor a Game destruktora automatikusan felszabadít mindent.
     Nincs free(), nincs fclose() – RAII.

  Összehasonlítás a C verzióval:
    C:   calloc → loadChooseQuestions → while(running){...} → free → return
    C++: Game objektum → loadQuestions → mainMenu → destruktor (automatikus)

────────────────────────────────────────────────────────────────────────────────
  2.2  Főmenü (Game::mainMenu)
────────────────────────────────────────────────────────────────────────────────

  Végtelen ciklus, amíg a felhasználó nem választja a [3]-at:

    [1] ÚJ JÁTÉK
      → Játékmód választás (1 = feleletválasztós, 2 = sorrendezős, 3 = vegyes)
      → Csak azok a módok elérhetők, amelyekhez van betöltött kérdés.
      → play(mode) hívás.

    [2] DICSŐSÉGLISTA
      → hsTable.display() hívás → betölti a CSV-t, rendezi, kiírja.

    [3] KILÉPÉS
      → A ciklus véget ér, visszatér a main()-be.

────────────────────────────────────────────────────────────────────────────────
  2.3  Egy teljes játékmenet (Game::play)
────────────────────────────────────────────────────────────────────────────────

  1) Név bekérése: getPlayerName()
     → Max 20 karakter, ';' kiszűrése (CSV védelem), üres → "Jatekos".

  2) Állapot nullázása: resetGameState()
     → currentLevel=0, finalPrize=0, gameOver=false, walkAway=false,
       used5050=false, usedAudience=false, hiddenResponses={-1,-1}.

  3) Fő játékciklus: while (currentLevel < 12 && !gameOver)

     Minden szinten:
       a) hiddenResponses = {-1, -1}  (előző 50:50 törlése)
       b) Szinttípus meghatározása:
            MODE_CHOOSE → mindig feleletválasztós
            MODE_ORDER  → mindig sorrendezős
            MODE_BOTH   → (currentLevel + 1) % 3 == 0 → sorrendezős
                          (tehát a 3., 6., 9., 12. kérdés sorrendezős)

       c) Fejléc kiírás:
            "4. KÉRDÉS  |  Tét: 50.000 Ft"
            "(Biztos nyereményed: 0 Ft)"   – vagy semmi, ha 0

       d) Véletlenszerű kérdés kiválasztása:
            - Feleletválasztós: chooseQuestions[currentLevel] vektorból
              rand() % vector.size()
            - Sorrendezős: orderQuestions vektorból
              rand() % vector.size()

       e) Kérdés megjelenítése: q.display()  (polimorf hívás)

       f) Válasz bekérése:
            - Feleletválasztós: A/B/C/D + segítségek (F, K) + kiszállás (Q)
            - Sorrendezős: 4 betűs kombináció (pl. "ABCD") + kiszállás (Q)
            - Sorrendezősnél NINCS segítség!

       g) Kiértékelés:
            - q.checkAnswer(input)  (polimorf hívás)
            - Helyes → currentLevel++, biztos szint üzenet ha kell
            - Helytelen → finalPrize = getSafePrize(currentLevel - 1)
              → gameOver = true

  4) Játék vége:
     - Ha mind a 12 szintet teljesítette → "GRATULÁLOK! ÖN MILLIOMOS LETT!"
       finalPrize = 5.000.000 Ft
     - Ha kiesett → "Kiestél! Nyereményed: [biztos szint összeg] Ft"
     - Ha kiszállt → "Megálltál! Nyereményed: [előző szint tétje] Ft"

  5) Eredmény mentése: hsTable.add(playerName, finalPrize)

────────────────────────────────────────────────────────────────────────────────
  2.4  Segítségek
────────────────────────────────────────────────────────────────────────────────

  CSAK feleletválasztós kérdéseknél érhetők el!

  50:50 segítség (Game::apply5050):
    → Kiszámolja a helyes válasz indexét: correctAnswer[0] - 'A'
    → Véletlenszerűen kiválaszt 2 ROSSZ választ → elrejti őket.
    → A hiddenResponses[2] tömbbe menti az elrejtett indexeket.
    → Kiírja a megmaradt 2 lehetőséget.
    → Ezeket a válaszokat a játékos NEM választhatja többé.
    → Egyszer használható a teljes játékmenetben (used5050 flag).

  Közönségszavazás (Game::applyAudience):
    → A helyes válasz 30-60% közötti százalékot kap: rand() % 31 + 30
    → A maradék %-ot véletlenszerűen elosztja a 3 rossz válasz között.
    → Kiírja: "A: 12%  B: 53%  C: 8%  D: 27%"
    → Egyszer használható (usedAudience flag).

  Kiszállás ("Q"):
    → Bármikor, bármelyik kérdéstípusnál elérhető.
    → Kiszállásnál az ELŐZŐ szint tétjét kapja meg a játékos.
    → Ha az 1. kérdésnél száll ki → 0 Ft.

────────────────────────────────────────────────────────────────────────────────
  2.5  Pénzlétra és biztos szintek
────────────────────────────────────────────────────────────────────────────────

  static const int PRIZE_LADDER[12] = {
      5.000, 10.000, 20.000, 50.000, 100.000, 200.000,
      300.000, 500.000, 800.000, 1.500.000, 3.000.000, 5.000.000
  };

  Biztos szintek: 5. kérdés (index 4) → 100.000 Ft
                  10. kérdés (index 9) → 1.500.000 Ft

  Ha a játékos kiesik:
    - Ha még nem érte el az 5. kérdést → 0 Ft
    - Ha az 5-9. kérdésnél esik ki → 100.000 Ft
    - Ha a 10. kérdés után esik ki → 1.500.000 Ft

────────────────────────────────────────────────────────────────────────────────
  2.6  Dicsőséglista működése
────────────────────────────────────────────────────────────────────────────────

  HighScoreTable::add(name, prize):
    → Lekéri az aktuális dátumot (localtime → "ÉÉÉÉ/HH/NN").
    → Létrehoz egy HighScoreEntry-t.
    → Append módban hozzáírja a CSV végéhez.
    → Ha a fájl üres volt → először fejlécet ír.

  HighScoreTable::display():
    → Beolvassa a CSV-t (load logika).
    → Rendezi csökkenő nyeremény szerint: std::sort + operator>.
    → Formázott kiírás: Játékos | Nyeremény | Dátum.

────────────────────────────────────────────────────────────────────────────────
  3.1  Question  (absztrakt ősosztály)
────────────────────────────────────────────────────────────────────────────────

  FÁJL: question.h / question.cpp

  CÉL: A két kérdéstípus közös alapja. Tartalmazza a kérdés szövegét,
       a kategóriát, a helyes választ és a 4 válaszlehetőséget.
       Absztrakt → NEM lehet közvetlenül példányosítani.

  TAGVÁLTOZÓK (# = protected):
  ┌────────────────┬──────────────────────────┬─────────────────────────────────┐
  │ Név            │ Típus                    │ Leírás                          │
  ├────────────────┼──────────────────────────┼─────────────────────────────────┤
  │ question       │ std::string              │ A kérdés szövege                │
  │ category       │ std::string              │ Kategória (pl. "Történelem")    │
  │ correctAnswer  │ std::string              │ Helyes válasz ("A" vagy "ABCD") │
  │ answers        │ std::vector<std::string>  │ 4 válaszlehetőség szövege      │
  └────────────────┴──────────────────────────┴─────────────────────────────────┘
  → Protected, mert a leszármazottak (ChooseQuestion, OrderQuestion)
    közvetlenül is elérhetik.

  METÓDUSOK:
  ┌─────────────────────────────────────────────────┬───────────────────────────────────────┐
  │ Metódus                                         │ Mit csinál?                           │
  ├─────────────────────────────────────────────────┼───────────────────────────────────────┤
  │ # Question(q, cat, correct, ans)                │ Protected konstruktor. Inicializálja  │
  │                                                 │ a 4 tagváltozót. Csak leszármazottak  │
  │                                                 │ hívhatják.                            │
  ├─────────────────────────────────────────────────┼───────────────────────────────────────┤
  │ + virtual ~Question() = default                 │ Virtuális destruktor. Kell, mert      │
  │                                                 │ polimorf hierarchia: ha Question*     │
  │                                                 │ pointerrel törlünk, a helyes dtor     │
  │                                                 │ hívódjon meg. default, mert RAII.     │
  ├─────────────────────────────────────────────────┼───────────────────────────────────────┤
  │ + virtual void display() const = 0              │ Tisztán virtuális (pure virtual).     │
  │                                                 │ A kérdés kiírása konzolra.            │
  │                                                 │ Nincs törzse → Question absztrakt.    │
  │                                                 │ Mindkét leszármazott máshogy írja ki. │
  ├─────────────────────────────────────────────────┼───────────────────────────────────────┤
  │ + virtual bool checkAnswer(input) const = 0     │ Tisztán virtuális. Ellenőrzi, hogy    │
  │                                                 │ a megadott válasz helyes-e.            │
  │                                                 │ Choose: 1 betű, Order: 4 betű.        │
  ├─────────────────────────────────────────────────┼───────────────────────────────────────┤
  │ + getQuestion() const                           │ Getter. const ref visszaadás.         │
  │ + getCategory() const                           │ Getter. const ref visszaadás.         │
  │ + getCorrectAnswer() const                      │ Getter. const ref visszaadás.         │
  │ + getAnswers() const                            │ Getter. const ref visszaadás.         │
  └─────────────────────────────────────────────────┴───────────────────────────────────────┘

  MIÉRT VIRTUÁLIS A display() ÉS A checkAnswer()?
    Mert a ChooseQuestion és az OrderQuestion máshogy jeleníti meg magát
    és máshogy ellenőriz. A polimorfizmus lehetővé teszi, hogy Question&
    vagy Question* típuson keresztül a helyes leszármazott metódus fusson.

  CÉL: Egy feleletválasztós kérdés. A C-beli ChooseQuestion struct

  └─────────────┴───────┴────────────────────────────────────────┘

  METÓDUSOK:
  ┌─────────────────────────────────────────────┬───────────────────────────────────────────┐
  │ Metódus                                     │ Mit csinál?                               │
  ├─────────────────────────────────────────────┼───────────────────────────────────────────┤
  │ + ChooseQuestion(diff, q, cat, correct, ans)│ Konstruktor. Meghívja az ős              │

  │ + void display() const override             │ Kiírja:                                   │

  │                                             │ Az input 1 betű: "A","B","C","D".         │

────────────────────────────────────────────────────────────────────────────────
  4.1  formatPrize algoritmus (Game::formatPrize)
────────────────────────────────────────────────────────────────────────────────

  CÉL: Egész számot "5.000.000" formátumú stringgé alakítani.
  BE:  int prize (pl. 5000000)
  KI:  std::string (pl. "5.000.000")

  LÉPÉSEK:
    1. Az int-et std::to_string()-gel stringgé alakítjuk: "5000000"
    2. Hátulról előre haladunk egy számlálóval.
    3. Minden 3. számjegy után egy '.' karaktert szúrunk be.
    4. Eredmény: "5.000.000"
    5. std::string visszaadás (nincs malloc, nincs free).

  A C-ben ehhez malloc + strdup + free kellett. C++-ban automatikus.

────────────────────────────────────────────────────────────────────────────────
  4.2  CSV betöltés (FileManager::loadChooseQuestions)
────────────────────────────────────────────────────────────────────────────────

  CÉL: A kerdesek.csv fájlból ChooseQuestion vektort előállítani.
  BE:  const std::string& filename
  KI:  std::vector<ChooseQuestion>

  CSV formátum: Nehézség;Kérdés;A;B;C;D;Válasz;Kategória  (7 db ';')

  LÉPÉSEK:
    1. std::ifstream megnyitás. Ha sikertelen → üres vektor + hibaüzenet.
    2. Fejlécsor átugrása (std::getline).
    3. Soronként beolvasás (std::getline):
       a) Pontosvesszők számlálása: std::count(line, ';')
          Ha nem 7 → continue (hibás sor kihagyása).
       b) Darabolás: std::istringstream + std::getline(ss, field, ';')
          → 8 mező: nehézség, kérdés, A, B, C, D, válasz, kategória
       c) Nehézség: std::stoi() → 1..12 tartomány ellenőrzés.
          Ha kívül esik → continue.
       d) ChooseQuestion objektum létrehozása → push_back.
    4. Vektor visszaadása (move semantics → nincs másolás).

  A loadOrderQuestions() ugyanez, de 6 pontosvesszővel és
  OrderQuestion objektumokkal (nincs nehézségi szint mező).

────────────────────────────────────────────────────────────────────────────────
  4.3  Dicsőséglista rendezés (HighScoreTable::display)
────────────────────────────────────────────────────────────────────────────────

  CÉL: Bejegyzéseket csökkenő nyeremény szerint kiírni.

  LÉPÉSEK:
    1. load() → entries vektor feltöltése a CSV-ből.
    2. std::sort() csökkenő rendezéssel:
         std::sort(entries.begin(), entries.end(),
                   [](const HighScoreEntry& a, const HighScoreEntry& b)
                   { return a > b; });
    3. Formázott kiírás: Game::formatPrize() minden bejegyzésre.

  A C-ben kézi selection sort volt (O(n²)). C++-ban std::sort (O(n log n)).

────────────────────────────────────────────────────────────────────────────────
  4.4  Kérdés kiválasztás (Game::play)
────────────────────────────────────────────────────────────────────────────────

  Minden szinten:

  1. Szinttípus:
       MODE_CHOOSE → mindig feleletválasztós
       MODE_ORDER  → mindig sorrendezős
       MODE_BOTH   → (currentLevel + 1) % 3 == 0 → sorrendezős
                     (3., 6., 9., 12. kérdés)

  2. Feleletválasztós → chooseQuestions[currentLevel] vektorból:
       rand() % vector.size()

  3. Sorrendezős → orderQuestions vektorból:
       rand() % vector.size()

  4. q.display()       → polimorf hívás (a helyes leszármazott display()-e)
  5. q.checkAnswer()   → polimorf hívás (a helyes leszármazott ellenőrzése)

================================================================================
  HIBAKEZELÉS
================================================================================

  - Fájl megnyitási hiba: if (!file.is_open()) → hibaüzenet, return.
  - Hibás CSV sor: pontosvesszők száma nem stimmel → continue.
  - Érvénytelen nehézség: std::stoi() + tartomány (1..12) → continue.
  - Üres játékosnév: if (name.empty()) name = "Jatekos";
  - ';' a névben: std::replace(..., ';', ' ') – CSV injection védelem.
  - Érvénytelen válasz: ciklusban bekérjük amíg érvényes nem lesz.
  - 50:50-vel kizárt válasz: ellenőrzés a hiddenResponses tömbbel.
